Claude Code Guide

A practical, copy-paste reference for developers who ship.

Getting Started

Claude Code is an agentic coding tool that lives in your terminal. Install it and launch with a single command.

npx -y @anthropic-ai/claude-code
Tip Use --dangerously-skip-permissions to skip prompts, or cycle to Auto mode with Shift + Tab.

Essential Commands

/init

Project Setup

Initialize project with a CLAUDE.md guide. Best for first-time setup.

/compact

Context Management

Wipes conversation history but keeps important focus instructions. Use when context > 80%.

/diff

Interactive Diff

Viewer for uncommitted changes. Use before committing.

/plan

Plan Mode

Claude plans before coding. Perfect for complex architectural tasks.

/rewind

Undo Changes

Rewind conversation and/or code to a previous point.

/btw

Quick Question

Side question without polluting main context.

Permissions & Config

Example: Solo Developer (Trust Mode)

High trust settings for personal projects. Place in ~/.claude/settings.json.

{
  "permissions": {
    "allow": [
      "Bash(npm *)",
      "Bash(git *)",
      "Read",
      "Edit",
      "Grep",
      "Glob",
      "WebFetch",
      "WebSearch",
      "mcp__*"
    ]
  }
}

Lifecycle Hooks

Auto-Format (Prettier)

Formats JS/TS files after every edit.

{
  "hooks": {
    "PostToolUse": [{
      "matcher": "Write|Edit",
      "hooks": [{
        "type": "command",
        "command": "jq -r '.tool_input.file_path' | xargs npx prettier --write 2>/dev/null; exit 0"
      }]
    }]
  }
}

Block Danger

Prevents rm -rf or forced pushes.

{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Bash",
      "hooks": [{
        "type": "command",
        "command": "jq -r '.tool_input.command' | grep -qE 'rm -rf|git push.*--force' && exit 2 || exit 0"
      }]
    }]
  }
}
